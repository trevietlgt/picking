# Picking App - fast navigation + history popup

## Điểm mới
- CONFIRM/SKIP chuyển vị trí gần như ngay lập tức
- Save chạy nền theo hàng đợi
- Có popup xem lịch sử mã hàng đã pick trong đơn đang làm

## Cách cập nhật
1. Ghi đè `index.html`
2. Ghi đè `app.js`
3. Commit/push GitHub
4. Ctrl + F5 để xoá cache
